9. Linux File System:

   - Tree Like structure
   - / : Root Directory
   - Sub directory inside / directory:
     - dev: store device related file and directories
     - bin: store user commands binaries
     - sbin: store superuser command binaries
     - proc: store process files
     - mnt: store manual mounted files
     - media: store automatically mounted files
     - temp: store temporary files
     - etc: store extra files required by system
     - home: store user directories
     - root: store superuser files and directories
     - boot: store files need for booting the linux
     - lib: store library files needed to run applications

10. Important Command:
    - cd: change directory: use to navigate directories using CLI
      - cd <path>
      - cd . : return pwd
      - cd ..: parent directory
      - cd - : previous working directory
      - cd ~:User Home directory
    - ps: command to view all running processes,their PID,etc.
