
# <span style="color:#a7c957"><strong>Computing and Cloud Computing — Fundamental Concepts</strong></span>

Understanding **computing** is essential before understanding **cloud computing**, because cloud computing is simply **a new way of delivering computing resources**.

Think of it as:

> **Computing = Using machines to process information and perform tasks.**
> **Cloud Computing = Using remote machines over a network to perform those tasks.**

# <a id="computing"></a> <span style="color:#6a994e"><strong>What Computing Is</strong></span>

Computing is the process of **using electronic systems to process data and perform tasks**.

Definition:

```text
Computing = Input → Processing → Output
```

Example tasks performed by computing systems:

* performing calculations
* storing information
* running applications
* processing data

Example:

```text
Calculator
Laptop
Server
Smartphone
```

All these devices perform **computing operations**.

Example workflow:

```text
User Input
   ↓
Computer Processes Data
   ↓
Result Displayed
```

---

# <a id="components"></a> <span style="color:#6a994e"><strong>Core Components of Computing</strong></span>

Computing systems consist of several essential components.

| Component    | Role                          |
| ------------ | ----------------------------- |
| CPU          | Executes instructions         |
| Memory (RAM) | Temporary data storage        |
| Storage      | Long-term data storage        |
| Network      | Communication between systems |
| Software     | Programs performing tasks     |

Example system:

```text
Computer
 ├── CPU
 ├── RAM
 ├── Storage
 ├── Network interface
 └── Operating System
```

These components work together to perform computing tasks.

# <a id="process"></a> <span style="color:#6a994e"><strong>How Computing Works Internally</strong></span>

Computing follows a structured cycle.

### Step 1 — Input

User provides data.

Example:

```text
Typing numbers in calculator
```

---

### Step 2 — Processing

CPU executes instructions.

Example:

```text
Add numbers
```

---

### Step 3 — Output

Result is displayed.

Example:

```text
Display result on screen
```

---

### Step 4 — Storage

Results may be saved for later use.

Example:

```text
Saving file on disk
```

Complete computing cycle:

```text
Input → Processing → Output → Storage
```

# <a id="cloud-definition"></a> <span style="color:#6a994e"><strong>What Cloud Computing Is</strong></span>

Cloud computing is a model where **computing resources are provided remotely through the internet**.

Definition:

```text
Cloud Computing = Computing using remote servers over the network
```

Instead of running applications on a local machine:

```text
Local computer performs processing
```

Cloud computing works like:

```text
User device → Internet → Remote server performs processing
```

Example:

```text
Laptop → AWS server → Results returned
```

Examples of cloud services:

* AWS
* Google Cloud
* Microsoft Azure

---

# <a id="difference"></a> <span style="color:#6a994e"><strong>Difference Between Computing and Cloud Computing</strong></span>

| Concept         | Explanation                                     |
| --------------- | ----------------------------------------------- |
| Computing       | Processing data using electronic devices        |
| Cloud Computing | Performing computing tasks using remote servers |

Example comparison:

| Task            | Local Computing   | Cloud Computing   |
| --------------- | ----------------- | ----------------- |
| File storage    | Local hard drive  | Cloud storage     |
| Data processing | Local CPU         | Remote server CPU |
| Software        | Installed locally | Hosted in cloud   |

---

# <a id="mechanics"></a> <span style="color:#6a994e"><strong>How Cloud Computing Works</strong></span>

Cloud computing involves several infrastructure components.

Basic workflow:

```text
User Device
   │
Internet
   │
Cloud Data Center
   │
Servers perform computation
```

Example scenario:

User uploads file:

```text
Laptop → Internet → Cloud Storage Server
```

Server processes data and returns result.

Example services provided by cloud:

```text
Virtual machines
Databases
Storage
AI platforms
```

These resources are provisioned **on demand**.

# <a id="mental-model"></a> <span style="color:#6a994e"><strong>Simple Mental Model</strong></span>

Traditional computing:

```text
Your computer does all the work
```

Cloud computing:

```text
Remote servers do the work
```

Example flow:

```text
User device
   ↓
Send request over internet
   ↓
Cloud servers process task
   ↓
Result returned to user
```

Key idea:

> **Computing is the process of performing tasks using electronic systems, while cloud computing delivers those computing resources remotely through network-connected servers.**
